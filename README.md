# Skills

To symlink another skill from this repository into `~/.agents/skills`, run this from the repository root:

```bash
ln -s "$(pwd)/skill_name" "$HOME/.agents/skills/skill_name"
```

To symlink `pi-agents.md` into the pi agent config as `AGENTS.md`, run:

```bash
ln -s /Users/gabe/development/gshahbazian/skills/pi-agents.md ~/.pi/agent/AGENTS.md
```
